Terminology
-----------

The key words "*MUST*", "*MUST NOT*", "*REQUIRED*", "*SHALL*", "*SHALL NOT*",
"*SHOULD*", "*SHOULD NOT*", "*RECOMMENDED*", "*NOT RECOMMENDED*", "*MAY*",
and "*OPTIONAL*" in this document are to be interpreted as described in
https://rfc-editor.org/info/bcp14[BCP 14]
{blank}[https://doi.org/10.17487/RFC2119[RFC2119]]
{blank}[https://doi.org/10.17487/RFC8174[RFC8174]]
when, and only when, they appear in all capitals, as shown here.

The term "slice" *SHALL* refer to a fixed-width, non-overlapping portion of
a word, `SLICE_WIDTH` bits wide. A word is divided into `NUM_SLICES` slices.
The exact bit range for a slice *SHALL* be interpreted as described in
requirement `REQ-REGFILE-020`.

The term "operation" *SHALL* refer to one full execution of `fu_op_i`,
from acceptance (`valid_i` and `ready_o` both asserted) to completion
(`ready_o reasserted).

IP Overview
-----------

A slice-serial functional unit (FU) for a RISC-V core, operating on one slice
of each operand per cycle. The module accepts an operation over a ready/valid
handshake, processes it over multiple cycles as driven by an externally
supplied cycle count, and writes the result back to the register file
by driving that register file's write port control signals.

=== Ports

.Port table.
[cols="1,1,1,2"]
|===
| Port Name | Direction | Width | Description

| `clk_i`
| input
| 1
| Rising-edge write clock.

| `rst_ni`
| input
| 1
| Active-low synchronous reset.

| `valid_i`
| input
| 1
| Asserted by the requester to present a new operation.

| `ready_o`
| output
| 1
| Asserted when the module is idle and is able to accept a new operation
from the requester. Will be asserted for at least one cycle when an
operation is completed.

| `cycle_i`
| input
| `SLICE_ADDR_WIDTH+1`
| Externally driven cycle counter for the operation in progress. Sized with
one extra bit as various operations require extra cycles for fetching
and/or writeback.

| `fu_op_i`
| input
| `fu_op_t`
| Selects the FU operation. Sampled on acceptance.

| `a_i`
| input
| `slice_t`
| Operand A slice for the current cycle.

| `b_i`
| input
| `slice_t`
| Operand B slice for the current cycle.

| `result_o`
| output
| `slice_t`
| Result slice for the current cycle.

| `rslice_o`
| output
| stem:[\lceil\log_2{(\texttt{NUM\_SLICES})}\rceil]
| Selects which slice is read this cycle. Drives the register file's
read slice selector.

| `wslice_o`
| output
| stem:[\lceil\log_2{(\texttt{NUM\_SLICES})}\rceil]
| Selects which slice is written to this cycle. Drives the register file's
write slice selector.
